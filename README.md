## Что добавлено в этом форке

- **WARP UDP filter** — отдельный переключаемый профиль обработки UDP-портов WARP: `500`, `1701`, `4500`, `8095`, `2408`.
- **Minecraft Java filter** — отдельная обработка TCP-порта `25565` для IP-адресов, CIDR-подсетей и доменов Minecraft-серверов.
- **Автовыбор стратегии в простое** — необязательная фоновая проверка стратегий с возвратом к предыдущей конфигурации, если более удачный вариант не найден.
- **AutoHostlist** — необязательное автоматическое добавление доменов, похожих на заблокированные, в отдельный список для TCP/443.
- **Локализация менеджера** — русский интерфейс для Windows с русским языком и английский для остальных языков.

Также сохранены основные возможности исходного проекта: набор стратегий `general*.bat`, установка стратегии как службы Windows, диагностика, тестирование конфигураций, пользовательские списки и управление фильтрами.

## Установка и первый запуск

1. Скачайте ZIP из [последнего релиза](https://github.com/MAKAKAIglitch/zapret-discord-youtube-warp/releases/latest).
2. Распакуйте архив в отдельную папку. Для совместимости с BAT-скриптами используйте простой путь, например `C:\zapret`, без кириллицы и специальных символов.
3. Запустите `service.bat`. Менеджер сам запросит права администратора, необходимые для установки и управления службой и драйвером WinDivert.
4. Откройте **Run Tests** → **Standard tests** → **All configs**, чтобы проверить стратегии на доступность тестовых HTTPS-адресов.
5. Вернитесь в меню и выберите **Install Service**. Выберите стратегию, которая лучше всего работает в вашей сети.

Для проверки стратегии вручную можно запустить соответствующий `general*.bat`. Не запускайте ручную стратегию одновременно с уже работающей службой `zapret`: сначала остановите или удалите установленную службу через менеджер.

> [!NOTE]
> Стратегии могут вести себя по-разному у разных провайдеров и со временем переставать работать. Проверка **Standard tests** оценивает доступность адресов из `utils/targets.txt`; она сама по себе не подтверждает успешное подключение туннеля WARP или работу каждого отдельного приложения.

## Менеджер `service.bat`

Менеджер объединяет настройку службы, фильтров, обновлений и диагностики.

| Пункт меню | Назначение |
|---|---|
| **Install Service** | Установить выбранную стратегию как службу Windows. |
| **Remove Services** | Остановить и удалить службу `zapret` и связанные службы WinDivert. |
| **Check Status** | Проверить состояние службы и процесса `winws.exe`. |
| **Game Filter** | Переключить дополнительную обработку игрового трафика. |
| **IPSet Filter** | Выбрать режим обработки IP-адресов из `ipset-all.txt`. |
| **Auto-Update Check** | Включить или выключить автоматическую проверку версии. |
| **Replace active fakes** | Заменить используемые файлы фейков файлами из `bin`. |
| **Update IPSet List** | Загрузить актуальный IPSet-список из исходного проекта Flowseal. |
| **Update Hosts File** | Проверить актуальность списка Hosts из исходного проекта Flowseal. |
| **Check for Updates** | Проверить версию менеджера относительно исходного проекта Flowseal. |
| **Run Diagnostics** | Проверить распространённые системные условия и возможные конфликты. |
| **Run Tests** | Запустить проверку стратегий и DPI-checker. |
| **Custom Fixes** | Настроить дополнительные функции WARP, Minecraft и автоматизации. |

### Важное замечание об обновлениях

Пункты **Check for Updates**, **Update IPSet List** и **Update Hosts File** в текущем коде обращаются к ресурсам оригинального Flowseal. Они не проверяют наличие нового релиза именно этого форка и не обновляют его сборку.

Чтобы получить новую версию `zapret-discord-youtube-warp`, проверяйте [релизы этого репозитория](https://github.com/MAKAKAIglitch/zapret-discord-youtube-warp/releases/latest).

### Режимы IPSet

`IPSet Filter` управляет тем, как стратегии используют список IP-адресов:

- `loaded` — используется содержимое `lists/ipset-all.txt`;
- `none` — список фактически не задаёт рабочие адреса для фильтрации;
- `any` — фильтр применяется ко всем IP-адресам, попадающим под соответствующее правило стратегии.

Режим `any` может затрагивать соединения, не связанные с тем ресурсом, который вы проверяете. Для обычной работы используйте режим, соответствующий вашей конфигурации.

## Cloudflare WARP

WARP устанавливается отдельно. Клиент Cloudflare не входит в этот репозиторий.

- [Официальная загрузка Cloudflare One Client](https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/)

### Как включить дополнительный WARP-фильтр

1. Установите и настройте Cloudflare WARP отдельно.
2. Запустите `service.bat`.
3. Откройте **Custom Fixes**.
4. Выберите **Toggle WARP UDP ports**.
5. Если служба `zapret` уже установлена, менеджер предложит пересобрать её с новыми настройками. Подтвердите пересборку, чтобы изменения вступили в силу.
6. Если стратегия запущена вручную, перезапустите соответствующий `general*.bat`.

При первом создании файла `utils/fix_filters.ini` WARP-фильтр включён по умолчанию. Текущее состояние отображается в главном меню.

Дополнительный профиль WARP обрабатывает UDP-порты:

| Порт | Протокол |
|---:|---|
| `500` | UDP |
| `1701` | UDP |
| `4500` | UDP |
| `8095` | UDP |
| `2408` | UDP |

Это список портов дополнительного профиля именно в данном форке, а не полный перечень всех сетевых портов, которые Cloudflare WARP может использовать в любых режимах.

### Если WARP не подключается

Универсальной стратегии для всех провайдеров нет. Проверьте несколько стратегий через **Run Tests**, сравните поведение WARP с запущенным zapret и без него, а также проверьте выбранный режим и состояние самого клиента WARP.

Ошибки вроде `CF_HAPPY_EYEBALLS_MITM_FAILURE`, `CF_DNS_LOOKUP_FAILURE` и `CF_CONNECTIVITY_FAILURE_UNKNOWN` могут возникать по разным причинам. Сам факт прохождения тестов zapret не означает, что рукопожатие WARP обязательно завершится успешно.

## Minecraft Java

В форке есть отдельный переключаемый профиль для Minecraft Java на TCP-порту `25565`.

### Списки серверов

- `lists/minecraft-servers.txt` — IP-адреса и CIDR-подсети. По одному адресу или диапазону на строку.
- `lists/minecraft-domains.txt` — домены серверов. По одному домену на строку; строки, начинающиеся с `#`, считаются комментариями.
- `lists/minecraft-domains-resolved.txt` — автоматически создаваемый список IP-адресов, полученных при разрешении доменов.

### Как настроить

1. Добавьте IP-адреса или CIDR-подсети в `minecraft-servers.txt`.
2. При необходимости добавьте домены в `minecraft-domains.txt`.
3. В `service.bat` откройте **Custom Fixes** → **Refresh Minecraft domain IP addresses**, чтобы обновить IP-адреса доменов.
4. Переключатель **Toggle Minecraft servers** включает или выключает дополнительный фильтр.
5. При изменении настроек установленной службы согласитесь на её пересборку либо перезапустите ручную стратегию.

Фильтрация доменов выполняется через DNS-разрешение IP-адресов и применяется к TCP/25565. Minecraft-серверы, использующие SRV-записи с нестандартным портом, автоматически не переключают порт фильтрации. Для таких серверов нужна отдельная настройка.

## Автоматические функции

В `service.bat` → **Custom Fixes** находятся две дополнительные функции. По умолчанию обе выключены.

### Auto-pick strategy while idle

Автоматический подбор стратегии в периоды низкой активности:

- проверка запускается планировщиком не чаще одного раза в 30 минут;
- тестирование начинается после минимум 15 минут бездействия пользователя и при низкой сетевой активности;
- функция работает только при запущенной службе `zapret`;
- во время тестирования служба временно останавливается;
- новая стратегия выбирается только при достаточном улучшении результата; иначе возвращается предыдущая;
- результаты записываются в `utils/auto-strategy.log`.

Подбор сравнивает доступность HTTPS-целей из `utils/targets.txt`. Это эвристика: она не гарантирует лучшую работу каждого сайта, игры, приложения или туннеля WARP.

### AutoHostlist

AutoHostlist добавляет отдельный профиль для TCP/443. Он анализирует похожие на блокировку ответы и записывает соответствующие домены в `lists/hostlist-auto.txt`, чтобы применять их при последующих соединениях.

Файл создаётся из `lists/hostlist-auto.txt.example`, если его ещё нет. Содержимое можно просматривать и редактировать вручную. Функция меняет обработку TCP/443, поэтому по умолчанию выключена.

## Пользовательские списки

Чтобы добавить свои адреса, используйте файлы в `lists/`:

| Файл | Для чего нужен |
|---|---|
| `list-general-user.txt` | Домены, которые нужно обрабатывать общими стратегиями. |
| `list-exclude-user.txt` | Домены, исключаемые из обработки. |
| `ipset-all.txt` | IP-адреса и CIDR-подсети для IPSet-фильтрации. |
| `ipset-exclude-user.txt` | IP-адреса и подсети, исключаемые из обработки. |
| `minecraft-servers.txt` | IP-адреса и CIDR-подсети Minecraft Java-серверов. |
| `minecraft-domains.txt` | Домены Minecraft Java-серверов. |
| `hostlist-auto.txt` | Домены, собранные функцией AutoHostlist. |

В текстовых списках указывайте по одному значению на строку. Пользовательские файлы `*-user.txt` создаются менеджером автоматически при первом запуске, если их ещё нет.

## Диагностика и частые вопросы

### Ни одна стратегия не работает

- Запустите **Run Diagnostics** и проверьте отображаемые предупреждения.
- В **Run Tests** сравните несколько конфигураций.
- Убедитесь, что одновременно не работают другие программы обхода или фильтрации трафика.
- Проверьте, что нужный домен или IP-адрес присутствует в соответствующем списке.

Стратегии не являются универсальными: результат зависит от сети и текущего поведения DPI.

### Не работает YouTube или Discord

- Проверьте несколько стратегий, а не только одну.
- Запустите диагностику через `service.bat` → **Run Diagnostics**.
- Для Discord можно воспользоваться предусмотренной там очисткой кэша приложения.
- Проверьте, одинаково ли ведёт себя ресурс в браузере и отдельном приложении.

### Не работает Telegram Web или голосовой чат Discord

В `service.bat` есть пункт **Update Hosts File**. Он проверяет локальный системный Hosts относительно файла исходного проекта Flowseal и при необходимости открывает загруженное содержимое для ручного применения.

Изменения системного файла Hosts влияют на разрешение доменных имён Windows. Перед ручным редактированием проверьте содержимое файла и сохраните его исходную копию.

### Не работают игры

Для игр могут требоваться отдельные IP-адреса, домены и порты. Проверьте **Game Filter**, содержимое `ipset-all.txt` и пользовательские списки. Для Minecraft Java в этом форке предусмотрен отдельный фильтр TCP/25565.

### Антивирус сообщает о WinDivert

WinDivert — драйвер для перехвата и фильтрации сетевого трафика, который используется zapret. Некоторые защитные программы могут классифицировать подобные низкоуровневые сетевые инструменты как RiskTool или потенциально нежелательное ПО.

Проверяйте происхождение скачанного архива и файлов. Не считайте любое предупреждение автоматически ложным: сверяйте имя обнаружения, файл и источник сборки.

## Состав проекта и источники

- `general*.bat` — стратегии запуска zapret.
- `service.bat` — менеджер службы и дополнительных настроек.
- `bin/` — исполняемые файлы, библиотеки, драйвер и файлы фейков, необходимые стратегиям.
- `lists/` — доменные и IP-списки, включая пользовательские списки.
- `utils/` — тесты, вспомогательные скрипты и настройки автоматизации.

Основой проекта является [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). В свою очередь, zapret разработан [bol-van](https://github.com/bol-van/zapret).
